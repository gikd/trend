# trend — 추세추종 워치리스트

"가는 게 더 가고, 좋은 섹터 안의 좋은 종목은 더 간다" 로직으로 코스피·코스닥을
매일 소팅해 **오늘 / 이번주 / 이번달** 볼 종목을 보여주는 정적 사이트.
평일 16:00 KST 자동 갱신. 아버지 공유용.

- 사이트: https://gikd.github.io/trend/
- 구조는 [etf-sector-tracker](https://github.com/gikd/etf-sector-tracker)와 동일:
  GitHub Actions가 `scan.py` 실행 → `docs/data.json` 커밋 → GitHub Pages 서빙.

## 로직

1. **유니버스** — 네이버 시총 API로 코스피+코스닥 전종목. 우선주(코드 끝자리 ≠0)·
   스팩·리츠·거래정지 제외. 당일 거래대금 5억+ 또는 시총 2,000억+만 일봉 수집.
2. **섹터 매핑** — 네이버 업종 API 79개 그룹. 섹터 강도 = 구성종목 r5·r21 중앙값,
   상위 섹터 소속 종목에 가점(sec_pct).
3. **지표** — fchart 일봉 280개로 r1/r5/r21/r63/r126, 52주 신고가 근접도,
   이평 정배열(20>60>120), 20일선 위 지속일, 거래대금 서지, 종가 강도,
   상한가 횟수(급등락 패널티). 리스트 편입은 20일 평균 거래대금 30억+.
4. **리스트** — 같은 지표를 다른 가중치로:
   - 오늘(10): 거래대금 서지 + 신고가 근접 + 고가권 마감. 게이트: 20일선 위·양봉·(서지≥1.5x 또는 신고가)
   - 이번주(10): 1개월 수익률 백분위 + 20일선 위 지속일. 게이트: 종가>20일선>60일선
   - 이번달(15): 3·6개월 수익률 백분위 + 섹터 가점. 게이트: 완전 정배열
5. **신규/이탈** — 직전 거래일 data.json과 비교해 NEW 뱃지·이탈 명단 표시.

## 로컬 실행

```bash
python3 scan.py                 # docs/data.json 생성 (표준 라이브러리만 사용)
python3 -m http.server -d docs  # http://localhost:8000
```

## 갱신

`.github/workflows/scan.yml` — 평일 07:00 UTC(16:00 KST) + 07:40 UTC 백업, `workflow_dispatch` 수동 실행 가능.

투자 참고 자료이며 매수·매도 권유가 아님.
